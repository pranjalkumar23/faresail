TravelDeals

Tracks flight and cruise prices and only surfaces genuine drops against each route's own history — no bookings, just alerts.

This is a static preview, not the live app. TravelDeals' live-deal feed reads from Postgres with scheduled ingestion/detector services behind it — GitHub Pages only serves static files, so the real app can't run here.
